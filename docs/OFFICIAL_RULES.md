# Official hackathon references

These are the pages to re-check before publishing the final submission:

- Rules: https://nebiusglobalaihackathon.devpost.com/rules
- Overview / submission requirements: https://nebiusglobalaihackathon.devpost.com/
- Judging guidance: https://nebiusglobalaihackathon.devpost.com/updates/46204-here-s-how-judging-works

Current rules require a working software application that runs on Nebius Token Factory or Nebius AI
Cloud, uses at least one NVIDIA open-source model, includes a public open-source repository with
setup instructions, and includes a public demo video under three minutes. The overview also asks
for a working demo URL for non-Physical-AI submissions.
